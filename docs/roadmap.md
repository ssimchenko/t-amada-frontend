# Frontend roadmap

## 1. Product discovery — готово

- [x] Зафиксировать основной пользовательский сценарий.
- [x] Разделить выбор четырёх услуг на понятные шаги.
- [x] Определить состояния заказа и отдельных компонентов.
- [x] Подготовить экраны успеха, ожидания и компенсации.

## 2. Frontend foundation — следующий этап

- [ ] Инициализировать React + TypeScript приложение.
- [ ] Настроить маршрутизацию и базовую структуру модулей.
- [ ] Перенести визуальный прототип в переиспользуемые компоненты.
- [ ] Добавить единые UI-состояния loading, empty и error.
- [ ] Настроить форматирование, lint и базовые проверки в CI.

## 3. Интеграция с API

- [ ] Подключить поиск предложений по четырём услугам.
- [ ] Реализовать создание составного заказа.
- [ ] Согласовать типизированные DTO и машинные коды ошибок.
- [ ] Показывать состояние каждой услуги и общий прогресс.
- [ ] Обновлять заказ через polling; оценить переход на SSE.
- [ ] Восстанавливать заказ после перезагрузки страницы.

## 4. Надёжность и демонстрация

- [ ] Happy path: все услуги подтверждены.
- [ ] Отказ отеля и компенсация авиабилета.
- [ ] Повторный запрос с тем же `idempotencyKey`.
- [ ] Таймаут с состоянием `UNKNOWN`, без слепого повтора.
- [ ] Ошибка компенсации и переход в `MANUAL_REVIEW`.
- [ ] Автотесты критического пользовательского сценария.

Roadmap будет уточняться вместе с контрактом оркестратора и задачами командного репозитория.
